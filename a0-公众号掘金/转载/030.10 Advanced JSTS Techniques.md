## 1. 异步IIFE的Void守卫

问题：立即调用的异步函数如果处理不当，会创建导致内存泄漏的"浮动Promise"。

```typescript
// ❌ 有风险 - 返回浮动Promise
(async () => {
  await initializeApp();
})();

// ✅ 安全 - 显式丢弃返回值
void (async () => {
  await initializeApp();
})();
```

`void`操作符显式丢弃Promise返回值，防止未处理的Promise拒绝。这种模式对于应用引导代码中的"即发即弃"异步操作至关重要哦。

## 2. 高分辨率异步计时

超越`console.time()`：使用Performance API获得微秒级精度：

```typescript
const measureAsync = async <T>(name: string, fn: () => Promise<T>): Promise<T> => {
  performance.mark(`${name}-start`);
  try {
    return await fn();
  } finally {
    performance.mark(`${name}-end`);
    performance.measure(name, `${name}-start`, `${name}-end`);
    const [entry] = performance.getEntriesByName(name);
    console.log(`⏱️ ${name}：${entry.duration.toFixed(3)}ms`);
    performance.clearMarks();
  }
};

// 使用方式：
await measureAsync("DatabaseTransaction", () => 
  db.transaction(complexQuery)
);
```

**关键优势**：自动生成详细的性能时间线，可在Chrome DevTools的Performance标签中查看。

## 3. 用于Promise编排的AbortController

取消任何异步操作——不仅仅是fetch请求：

```typescript
const createCancellablePool = (promises: Promise<any>[], signal: AbortSignal) => {
  return Promise.all(promises.map(p => 
    new Promise((resolve, reject) => {
      // 监听取消事件
      signal.addEventListener("abort", () => 
        reject(new DOMException("已取消", "AbortError")));
      
      // 正常进行
      p.then(resolve).catch(reject);
    })
  ));
};

// 使用方式：
const controller = new AbortController();

// 2秒后取消所有操作
setTimeout(() => controller.abort(), 2000);

await createCancellablePool([
  analyticsSync(),
  cacheHydration(),
], controller.signal);
```

**关键用例**：用户导航中断——当用户更改路由时取消后台任务。

## 4. 使用生成器实现惰性Promise流

按需处理异步数据，减少内存开销：

```typescript
async function* streamResults<T>(urls: string[]) {
  for (const url of urls) {
    const response = await fetch(url);
    yield response.json() as T;
  }
}

// 按需消费
const videoStream = streamResults<Video>(videoUrls);

for await (const video of videoStream) {
  if (shouldStopProcessing(video)) break;
  renderPreview(video);
}
```

**性能优势**：通过避免"全内存"反模式，以恒定内存占用处理TB级数据集。

## 5. 掌握Typed Arrays处理二进制数据

无需复制数据即可合并ArrayBuffer：

```typescript
const mergeBuffers = (buffers: ArrayBuffer[]) => {
  const total = buffers.reduce((sum, b) => sum + b.byteLength, 0);
  const result = new Uint8Array(total);
  
  let offset = 0;
  buffers.forEach(buffer => {
    result.set(new Uint8Array(buffer), offset);
    offset += buffer.byteLength;
  });
  
  return result.buffer;
};

// 额外技巧：零复制切片
const sliceWithoutCopy = (buffer: ArrayBuffer, start: number, end: number) => {
  return buffer.slice(start, end);
};
```

**改变游戏规则**：WebAssembly互操作、WebGL纹理处理和WebSocket二进制流。

## 7. 安全的属性枚举

避免工具函数中的原型污染：

```typescript
const getSafeKeys = (obj: object) => {
  return Object.entries(Object.getOwnPropertyDescriptors(obj))
    .filter(([_, desc]) => desc.enumerable)
    .map(([key]) => key);
};

// 具有null原型的{}
const safeDict = Object.create(null); 
safeDict.data = "test";

console.log(getSafeKeys(safeDict)); // ["data"] 
// 不像Object.keys()可能继承属性
```

**安全影响**：防止从污染的原型中意外泄漏键。

## 8. Promise池并发控制

精确控制并行执行：

```typescript
class PromisePool {
  private running = 0;
  private queue: (() => void)[] = [];

  constructor(private concurrency: number) {}

  async run<T>(task: () => Promise<T>): Promise<T> {
    return new Promise((resolve, reject) => {
      const execute = async () => {
        this.running++;
        try {
          resolve(await task());
        } catch (err) {
          reject(err);
        } finally {
          this.running--;
          this.next();
        }
      };

      this.queue.push(execute);
      this.next();
    });
  }

  private next() {
    while (this.queue.length && this.running < this.concurrency) {
      this.queue.shift()!();
    }
  }
}

// 使用方式：
const pool = new PromisePool(3); // 数据库最大连接数
await pool.run(() => generateReport());
```

**数据库保护**：防止无服务器环境中的连接池耗尽。

## 9. 通过Proxy实现可观察的Promise

无需包装库即可跟踪Promise状态：

```typescript
function trackPromise<T>(promise: Promise<T>) {
  const state = {
    status: "pending" as "pending" | "fulfilled" | "rejected",
    value: null as T | null 
  };

  const proxy = new Proxy(promise, {
    get(target, prop) {
      if (prop === "status") return state.status;
      if (prop === "value") return state.value;
      return Reflect.get(target, prop);
    }
  });

  promise
    .then(result => {
      state.status = "fulfilled";
      state.value = result;
    })
    .catch(() => {
      state.status = "rejected";
    });
  return proxy;
}

// 使用方式：
const dataPromise = trackPromise(fetch("/api/data"));
// React组件示例：
useEffect(() => {
  dataPromise.then(data => {
    console.log(`状态：${dataPromise.status}`); // "fulfilled"
  });
}, []);
```

**用户体验优势**：非常适合渲染加载状态，无需单独的状态变量。

## 10. WeakRef缓存模式

无内存泄漏的缓存：

```typescript
class TemporaryCache {
  private cache = new Map<string, WeakRef<object>>();
  private cleanup = new FinalizationRegistry((key: string) => {
    this.cache.delete(key);
  });

 set(key: string, value: object) {
    this.cache.set(key, new WeakRef(value));
    this.cleanup.register(value, key, value);
  }

 get(key: string): object | undefined {
    const ref = this.cache.get(key);
    return ref?.deref();
  }
}

// 使用方式：
const cache = new TemporaryCache();
cache.set("user:123", heavyUserObject);

// 当heavyUserObject被垃圾回收时
// 缓存条目会自动移除
```

**用例**：非常适合大型对象的内存缓存，其中过时条目应自动驱逐。
