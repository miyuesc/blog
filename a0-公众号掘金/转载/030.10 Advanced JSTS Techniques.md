## 1. The Void Guard for Async IIFEs

The Problem: Immediately-invoked async functions can create “floating promises” that cause memory leaks when not properly handled.

```typescript
// ❌ Risky - returns floating promise
(async () => {
  await initializeApp();
})();

// ✅ Safe - explicitly discards return
void (async () => {
  await initializeApp();
})();
```

The `void` operator explicitly discards the promise return value, preventing unhandled promise rejections. This pattern is essential for fire-and-forget async operations in application bootstrap code.

## 2. High-Resolution Async Timing

Beyond `console.time()`: Use the Performance API for microsecond precision:

```typescript
const measureAsync = async <T>(name: string, fn: () => Promise<T>): Promise<T> => {
  performance.mark(`${name}-start`);
  try {
    return await fn();
  } finally {
    performance.mark(`${name}-end`);
    performance.measure(name, `${name}-start`, `${name}-end`);
    const [entry] = performance.getEntriesByName(name);
    console.log(`⏱️ ${name}: ${entry.duration.toFixed(3)}ms`);
    performance.clearMarks();
  }
};

// Usage:
await measureAsync("DatabaseTransaction", () => 
  db.transaction(complexQuery)
);
```

**Key Advantage**: Automatically generates detailed performance timelines visible in Chrome DevTools’ Performance tab.

## 3. AbortController for Promise Orchestration

Cancel any async operation — not just fetch requests:

```typescript
const createCancellablePool = (promises: Promise<any>[], signal: AbortSignal) => {
  return Promise.all(promises.map(p => 
    new Promise((resolve, reject) => {
      // Listen for abort event
      signal.addEventListener("abort", () => 
        reject(new DOMException("Cancelled", "AbortError")));
      
      // Proceed normally
      p.then(resolve).catch(reject);
    })
  );
};

// Usage:
const controller = new AbortController();

// Cancel all after 2 seconds
setTimeout(() => controller.abort(), 2000);

await createCancellablePool([
  analyticsSync(),
  cacheHydration(),
], controller.signal);
```

**Critical Use Case:** User navigation interrupts — cancel background tasks when users change routes.

## 4. Lazy Promise Streams with Generators

Process async data on-demand to reduce memory overhead:

```typescript
async function* streamResults<T>(urls: string[]) {
  for (const url of urls) {
    const response = await fetch(url);
    yield response.json() as T;
  }
}

// Consume as needed
const videoStream = streamResults<Video>(videoUrls);

for await (const video of videoStream) {
  if (shouldStopProcessing(video)) break;
  renderPreview(video);
}
```

**Perf Benefit**: Processes Terabyte datasets with constant memory usage by avoiding “all-in-memory” anti-patterns.

## 5. Binary Data Mastery with Typed Arrays

Merge ArrayBuffers without data copying:

```typescript
const mergeBuffers = (buffers: ArrayBuffer[]) => {
  const total = buffers.reduce((sum, b) => sum + b.byteLength, 0);
  const result = new Uint8Array(total);
  
  let offset = 0;
  buffers.forEach(buffer => {
    result.set(new Uint8Array(buffer), offset);
    offset += buffer.byteLength;
  });
  
  return result.buffer;
};

// Bonus: Zero-copy slicing
const sliceWithoutCopy = (buffer: ArrayBuffer, start: number, end: number) => {
  return buffer.slice(start, end);
};
```

**Game Changer:** WebAssembly interop, WebGL texture processing, and WebSocket binary streaming.

## 7. Safe Property Enumeration

Avoid prototype pollution in utility functions:

```typescript
const getSafeKeys = (obj: object) => {
  return Object.entries(Object.getOwnPropertyDescriptors(obj))
    .filter(([_, desc]) => desc.enumerable)
    .map(([key]) => key);
};

// {} with null prototype
const safeDict = Object.create(null); 
safeDict.data = "test";

console.log(getSafeKeys(safeDict)); // ["data"] 
// Unlike Object.keys() which may inherit properties
```

**Security Impact:** Prevents unexpected key leakage from polluted prototypes.

## 8. Promise Pool Concurrency

Control parallel execution with surgical precision:

```typescript
class PromisePool {
  private running = 0;
  private queue: (() => void)[] = [];

  constructor(private concurrency: number) {}

  async run<T>(task: () => Promise<T>): Promise<T> {
    return new Promise((resolve, reject) => {
      const execute = async () => {
        this.running++;
        try {
          resolve(await task());
        } catch (err) {
          reject(err);
        } finally {
          this.running--;
          this.next();
        }
      };

      this.queue.push(execute);
      this.next();
    });
  }

  private next() {
    while (this.queue.length && this.running < this.concurrency) {
      this.queue.shift()!();
    }
  }
}

// Usage:
const pool = new PromisePool(3); // DB max connections
await pool.run(() => generateReport());
```

**Database Protection**: Prevents connection pool exhaustion in serverless environments.

## 9. Observable Promises via Proxy

Track promise state without wrapper libraries:

```typescript
function trackPromise<T>(promise: Promise<T>) {
  const state = { 
    status: "pending" as "pending" | "fulfilled" | "rejected",
    value: null as T | null 
  };

  const proxy = new Proxy(promise, {
    get(target, prop) {
      if (prop === "status") return state.status;
      if (prop === "value") return state.value;
      return Reflect.get(target, prop);
    }
  });

  promise
    .then(result => {
      state.status = "fulfilled";
      state.value = result;
    })
    .catch(() => {
      state.status = "rejected";
    });
  return proxy;
}

// Usage:
const dataPromise = trackPromise(fetch("/api/data"));
// React component example:
useEffect(() => {
  dataPromise.then(data => {
    console.log(`State: ${dataPromise.status}`); // "fulfilled"
  });
}, []);
```

**UX Benefit:** Perfect for rendering loading states without separate state variables.

## 10. WeakRef Caching Patterns

Cache without memory leaks:

```typescript
class TemporaryCache {
  private cache = new Map<string, WeakRef<object>>();
  private cleanup = new FinalizationRegistry((key: string) => {
    this.cache.delete(key);
  });

 set(key: string, value: object) {
    this.cache.set(key, new WeakRef(value));
    this.cleanup.register(value, key, value);
  }

 get(key: string): object | undefined {
    const ref = this.cache.get(key);
    return ref?.deref();
  }
}

// Usage:
const cache = new TemporaryCache();
cache.set("user:123", heavyUserObject);

// When heavyUserObject is GC'd 
// cache entry auto-removes
```

**Use Case:** Ideal for in-memory caches of large objects where stale entries should auto-evict.
