#### 🧠 20个现代CSS技巧，前端人必会！

#### 1. clamp()——响应式字体大小一把梭

- **是什么**：`clamp()`让你字体大小随视口宽度自适应。
- **为什么用**：不用再写一堆媒体查询调字体了。
- **怎么用**：

```css
font-size: clamp(1rem, 2vw, 2rem);
```

- **实战场景**：做首页大标题、营销文案，字体自适应超丝滑。

#### 2. :has()——父元素也能“看见”孩子了

- **是什么**：可以根据子元素的存在来给父元素加样式。
- **为什么用**：原生条件样式，CSS终于有“if”了！
- **怎么用**：

```css
article:has(img) {
  border: 1px solid #ccc;
}
```

- **实战场景**：比如卡片里有图片就高亮，没有就不加边框。

#### 3. 滚动吸附（Scroll Snap）——原生轮播/滑块so easy

- **是什么**：让滚动时自动吸附到指定位置。
- **为什么用**：不用JS也能做丝滑滚动体验。
- **怎么用**：

```css
.container {
  scroll-snap-type: x mandatory;
}
.item {
  scroll-snap-align: center;
}
```

- **实战场景**：轮播图、图片滑块、新手引导页。

#### 4. aspect-ratio——宽高比再也不用padding hack

- **是什么**：直接给元素定宽高比。
- **为什么用**：视频、卡片再也不用“填充黑科技”了。
- **怎么用**：

```css
.video {
  aspect-ratio: 16 / 9;
}
```

- **实战场景**：YouTube嵌入、相册缩略图、商品卡片。

#### 5. @layer——级联层，样式优先级一目了然

- **是什么**：给大项目的样式分层，谁覆盖谁一清二楚。
- **为什么用**：复杂项目里样式不再“打架”。
- **怎么用**：

```less
@layer reset, base, components, utilities;
```

- **实战场景**：大型项目里，工具类和基础样式分层管理。

#### 6. CSS变量（Custom Properties）——主题换肤so easy

- **是什么**：定义可复用的颜色、间距等变量。
- **为什么用**：主题切换、维护都方便。
- **怎么用**：

```css
:root {
  --primary-color: #00bcd4;
}
button {
  background: var(--primary-color);
}
```

- **实战场景**：设计系统、全局换肤、组件主题化。

#### 7. 容器查询（Container Queries）——组件级响应式

- **是什么**：根据父容器大小给子元素加样式。
- **为什么用**：组件真正做到“随地生长”。
- **怎么用**：

```css
@container (min-width: 500px) {
  .card {
    flex-direction: row;
  }
}
```

- **实战场景**：CMS、后台里可复用的卡片、组件。

#### 8. backdrop-filter——毛玻璃/模糊特效一行搞定

- **是什么**：给背景加模糊、玻璃特效。
- **为什么用**：UI高级感up，代码量down。
- **怎么用**：

```css
.glass {
  backdrop-filter: blur(10px);
}
```

- **实战场景**：弹窗、浮层、毛玻璃导航栏。

#### 9. accent-color——原生美化表单控件

- **是什么**：自定义checkbox、radio、input的主题色。
- **为什么用**：不用再写一堆hack覆盖原生样式。
- **怎么用**：

```css
input {
  accent-color: hotpink;
}
```

- **实战场景**：品牌表单、个性化主题。

#### 10. :is()和:where()——多选器合并，优雅又不“打架”

- **是什么**：多个选择器合并，优先级还低。
- **为什么用**：代码更简洁，样式不乱套。
- **怎么用**：

```css
:is(h1, h2, h3) {
  margin-bottom: 1rem;
}
```

- **实战场景**：统一标题、表单等样式。

#### 11. 滚动联动动画（Scroll-Linked Animations）——滚动驱动动画so easy

- **是什么**：动画随滚动进度联动。
- **为什么用**：讲故事、做炫酷页面必备。
- **怎么用**（部分示例）：

```css
@scroll-timeline my-timeline;
.fade-in {
  animation-timeline: my-timeline;
}
```

- **实战场景**：首页大图、视差滚动、画廊。

#### 12. subgrid——嵌套网格对齐so easy

- **是什么**：子元素继承父网格布局。
- **为什么用**：嵌套内容对齐不再头疼。
- **怎么用**：

```css
.child {
  display: subgrid;
  grid-template-columns: subgrid;
}
```

- **实战场景**：卡片嵌套、复杂布局。

#### 13. 文本溢出省略号（ellipsis）——一行代码，UI更清爽

- **是什么**：超出文本自动加“...”
- **为什么用**：小屏幕、移动端UI更友好。
- **怎么用**：

```css
.truncate {
  overflow: hidden;
  white-space: nowrap;
  text-overflow: ellipsis;
}
```

- **实战场景**：新闻卡片、后台、文件名展示。

#### 14. CSS Grid自动填充/自适应——响应式布局so easy

- **是什么**：根据空间自动调整列数。
- **为什么用**：不用写断点，布局自适应。
- **怎么用**：

```css
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
```

- **实战场景**：商品列表、相册。

#### 15. CSS遮罩（mask）——自定义形状so easy

- **是什么**：用图片、渐变、SVG做遮罩。
- **为什么用**：做出各种炫酷形状和交互。
- **怎么用**：

```css
.masked {
  mask-image: url(mask.svg);
  mask-mode: alpha;
}
```

- **实战场景**：头像、转场动画。

#### 16. CSS原生动画（keyframes）——动效不用JS

- **是什么**：用CSS写动画。
- **为什么用**：性能好，代码少。
- **怎么用**：

```css
@keyframes fade {
  from { opacity: 0; }
  to { opacity: 1; }
}
.fade {
  animation: fade 1s ease-in;
}
```

- **实战场景**：加载动画、引导页。

#### 17. 逻辑属性（Logical Properties）——国际化so easy

- **是什么**：用margin-inline、padding-block等属性，自动适配RTL/LTR。
- **为什么用**：多语言、国际化项目必备。
- **怎么用**：

```css
padding-inline: 1rem;
```

- **实战场景**：全球化Web应用。

#### 18. 新媒体查询：prefers-color-scheme——原生暗黑模式

- **是什么**：根据系统主题自动切换样式。
- **为什么用**：原生支持暗黑/亮色模式。
- **怎么用**：

```css
@media (prefers-color-scheme: dark) {
  body {
    background: #111;
    color: #eee;
  }
}
```

- **实战场景**：主题自适应App。

#### 19. animation-composition——多动画叠加so easy

- **是什么**：多动画叠加，效果更丝滑。
- **为什么用**：动效更丰富，过渡更自然。
- **怎么用**：

```css
animation-composition: accumulate;
```

- **实战场景**：多层动效、复杂动画。

#### 20. 新视口单位（svh, lvh）——移动端全屏不再“露底”

- **是什么**：动态单位，真实反映视口高度。
- **为什么用**：解决移动端100vh“露底”bug。
- **怎么用**：

```css
height: 100svh;
```

- **实战场景**：移动端全屏区块。
