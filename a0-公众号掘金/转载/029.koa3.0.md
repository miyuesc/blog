# 八年磨一剑，Koa 3.0 正式发布！

> [Oliver Foster](https://medium.com/@haiou-a)

**2025年4月28日** — Node.js生态系统今天迎来重大升级：Koa.js 3.0正式发布啦！

从2017年开始规划，历经8年打磨，这个由Express原班人马打造的经典轻量级Web框架，终于以全新面貌回归了。

Koa 3.0不只是版本号的跳跃，更是Node.js现代化进程中的一个重要里程碑呢。

### Koa 3.0有哪些重大更新？

#### 1. 最低支持Node.js v18，拥抱现代特性

Koa 3.0将最低要求的Node.js版本提升到了v18，充分利用现代V8引擎的性能和安全优势。

对开发者来说，这意味着你可以放心使用Fetch API和node:test等原生特性，让项目构建在更坚实的基础上。

```javascript
// 现在你可以在Koa 3.0项目中直接使用fetch啦
const response = await fetch('https://api.example.com/data');
const data = await response.json();
```

*再也不用导入第三方fetch库了；Node.js v18+已经内置了它。*

#### 2. 彻底告别Generator，全面拥抱async/await

还记得Koa 1.x时代的Generator函数吗？

Koa 3.0已经完全移除了对它们的支持。

现在所有中间件都必须基于async/await。

这不仅让异步流程控制更直观，还让编码风格与现代JavaScript完美契合。

```javascript
// Koa 1.x
app.use(function* (next) {
  yield next;
  this.body = 'Hello Koa 1.x';
});

// Koa 3.0
app.use(async (ctx, next) => {
  await next();
  ctx.body = 'Hello Koa 3.0';
});
```

#### 3. 原生支持WHATWG响应体，实现前后端更好统一

新版本支持WHATWG标准的响应体对象（如Blob和FormData），让Koa能与浏览器的Fetch API无缝对接。

全栈开发者再也不用担心数据格式转换问题，前后端协作更顺畅啦。

```javascript
import { Blob } from 'buffer';

app.use(async ctx => {
  ctx.body = new Blob(['Hello, Koa 3.0!']);
});
```

*直接返回WHATWG标准对象，实现客户端和服务器之间数据格式的一致性，大大提升开发体验！*

#### 4. 增强的流式响应能力，支持自定义流

Koa 3.0支持直接使用自定义Node.js流作为响应体，极大提升了大文件、音频和视频的传输效率。

不管你是用archiver创建zip压缩包，还是处理大规模数据流，Koa现在都能轻松应对。

```go
import archiver from 'archiver';

const archive = archiver('zip');
// 假设有一个大文件流
const stream = ...
archive.append(stream, { name: 'archive.zip' });
res.body = archive;
```

*你可以直接将Node.js流对象赋值给* *`ctx.body`* *，实现高效的流式传输。*

#### 5. 使用AsyncLocalStorage，随时随地访问请求上下文

以前在中间件外部获取上下文（ctx）是不是很麻烦？

现在，通过app.currentContext，你可以从任何地方访问当前请求的上下文信息。

这让工具函数、日志记录和第三方库集成变得更优雅、更高效。

```cpp
const ctx = app.currentContext;
```

*旧问题：*

```javascript
// Koa v2的方式
app.use(async (ctx, next) => {
  // ctx只能在这里访问
  // 如果你调用另一个函数，必须手动传递ctx
someFunction(ctx);
  await next();
});

function someFunction(ctx) {
  // 必须接收ctx作为参数
}
```

*Koa 3.0的新方式：*

```csharp
app.use(async (ctx, next) => {
  await next();
});

function someFunction() {
  // 从任何地方获取当前请求的ctx
  const ctx = app.currentContext;
}
```

#### 6. 使用URLSearchParams实现更标准化的参数解析

Koa 3.0用WHATWG URLSearchParams API取代了原生的querystring模块，确保参数解析行为与浏览器一致。

#### 7. API优化，提升开发者体验

- 调整了`ctx.throw`的调用签名，让错误处理更清晰。
- 移除了`.redirect('back')`，替换为`.back(fallback_url)`，实现更安全的重定向逻辑。
- 优化了`req.origin`的返回逻辑，在CORS场景中能更准确地识别来源。
- 移除了对`ENOENT`错误的特殊处理。现在开发者需要自己处理流错误，这增加了灵活性和一致性。
- 全面升级依赖，增强安全性和兼容性

核心依赖如type-is、http-errors、cookies、statuses和supertest都已升级到最新版本，修复了已知漏洞，确保项目安全。
