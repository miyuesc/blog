# 为什么选择Ultracite？不只是另一个代码检查器 🧩

大多数工具都承诺"零配置"，但最终还是让你在插件、规则和编辑器设置之间手忙脚乱。而Ultracite构建在Biome（Rome的精神继承者）之上，并且更进一步：

- **统一体验**：代码检查、格式化、代码转换和AI协作——全在一个工具里搞定。
- **即时设置**：一条命令，你的项目就准备好进行现代开发啦。
- **AI优先设计**：不只是兼容AI，而是为增强AI能力而设计的哦。

> *"Ultracite不只是一个工具——它是下一代前端团队的工作哲学。" ✨*

# 快速开始：一条命令搞定一切 ⚡

忘掉那些与`.eslintrc`、`.prettierrc`和没完没了的插件安装搏斗的日子吧。有了Ultracite，设置就这么简单：

```shell
npx ultracite init
```

你会被引导着做几个选择（包管理器、编辑器、钩子），然后Ultracite会：

- 安装Biome、Husky和所有依赖
- 生成`biome.json`配置
- 设置VSCode/Cursor/Zed集成
- 添加用于格式化的pre-commit钩子
- 创建AI可读的样式指南

**再也不会有"在我机器上能运行"的问题啦！** 🖥️

# 现代化规则，为团队准备就绪 👥

Ultracite自带一套全面、有主见的规则集：

- 严格的TypeScript
- React/Next.js最佳实践
- Node.js约定
- 无障碍（a11y）检查
- 一致的样式（2空格缩进、最大行宽等）

你可以覆盖任何规则，但默认设置对大多数现代项目来说已经足够健壮了。

**biome.json示例：**

```json
{
  "extends": ["ultracite"],
  "rules": {
    "style/indentation": 2,
    "style/maxLineLength": 100
  }
}
```

# AI原生：与你的副驾驶一起编码 🤖

与传统工具不同，Ultracite是为AI时代构建的：

- 为AI工具生成**自动Markdown样式指南**，供它们阅读和遵循
- **MCP API**：实时向AI助手公开你的项目样式规则
- **不再需要"调整提示词"**——你的AI从一开始就知道规则

**MCP示例：**

```json
{
  "mcpServers": {
    "ultracite": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.ultracite.ai/api/mcp/http"
      ]
    }
  }
}
```

# 无缝团队集成 🔗

Ultracite会为你配置一切：

- **Husky**：提交前格式化

- **编辑器设置**：VSCode、Cursor、Zed——全部设置好

再也不会有构建失败或队友之间的样式差异了。
