# Getting Started: One Command to Rule Them All ⚡

Forget the days of wrestling with `.eslintrc`, `.prettierrc`, and endless plugin installs. With Ultracite, setup is as simple as:

```shell
npx ultracite init
```

You’ll be guided through a few choices (package manager, editor, hooks), and Ultracite will:

- Install Biome, Husky, and all dependencies
- Generate a `biome.json` config
- Set up VSCode/Cursor/Zed integration
- Add pre-commit hooks for formatting
- Create AI-readable style guides

**No more “it works on my machine” moments!** 🖥️

# Modern Rules, Ready for Teams 👥

Ultracite ships with a comprehensive, opinionated ruleset:

- Strict TypeScript
- Best practices for React/Next.js
- Node.js conventions
- Accessibility (a11y) checks
- Consistent style (2-space indent, max line width, etc.)

You can override any rule, but the defaults are robust enough for most modern projects.

**Example biome.json:**

```json
{
  "extends": ["ultracite"],
  "rules": {
    "style/indentation": 2,
    "style/maxLineLength": 100
  }
}
```

# AI-Native: Coding with Your Copilot 🤖

Unlike traditional tools, Ultracite is built for the AI era:

- **Auto-generated Markdown style guides** for AI tools to read and follow
- **MCP API**: Exposes your project’s style rules to AI assistants in real time
- **No more “prompt tweaking”** — your AI knows the rules from the start

**MCP Example:**

```json
{
  "mcpServers": {
    "ultracite": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://www.ultracite.ai/api/mcp/http"
      ]
    }
  }
}
```
