数据不会说谎。COVID-19 是科技行业的一个转折点。当时涌现了许多新的科技公司和初创企业，就业机会迅速增加。为了满足需求，公司们都在疯狂招人。

然而，这种增长并不平衡，过度招聘成了问题。后来，全球经济衰退来袭，从2022年开始，科技行业开始大规模裁员。成千上万的专业人士失去了工作，其中不乏经验丰富、背景强大的人。

现在，公司的招聘流程已经发生了翻天覆地的变化。过去，一两次面试就能搞定一份工作；而现在，求职者要经历三四轮面试。市场上有这么多技术过硬的专业人士，公司自然变得更加挑剔，只想招最顶尖的人才。

结果就是，招聘流程变慢了，说实话，找工作也变得难多了。你可以在我之前的文章中找到更多关于[科技行业裁员](https://taylanhanr.substack.com/p/why-tech-layoffs)的细节。

**今天，咱们重点聊聊一个重要的前端面试问题。**

很多求职者的简历上都写着这样的话：

> *"通过代码重构、数据重组、消除代码重复和简化条件表达式，将应用性能提升了30%。"*

这在简历上听起来很厉害，但真正的问题是——他们真的能在面试中像专家一样解释清楚吗？

如果面试官问：**"你用了什么方法来实现这个提升的？"**

最好的回答方式之一，就是聊聊JavaScript中的**Tree Shaking**技术。咱们来解释一下，Tree Shaking到底是什么。

> Tree Shaking是JavaScript语境中常用的一个术语，用来描述移除无用代码（dead code）的过程。它依靠[import](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import)和[export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)语句来检测代码模块是否在JavaScript文件之间被导出和导入使用。现代打包工具如**Webpack、Rollup和ESBuild**都会用到它来优化性能。

> 在现代JavaScript应用中，我们使用模块打包工具（如[webpack](https://webpack.js.org/)或[Rollup](https://github.com/rollup/rollup)）在将多个JavaScript文件打包成单个文件时自动移除无用代码。这对于准备生产环境代码非常重要，可以让代码结构更清晰、文件大小更小。

#### 像专家一样回答这个问题

> "我通过**实现Tree Shaking**来优化应用性能，它能帮助从最终的JavaScript包中剔除未使用的代码。**这对减小包体积和提升加载速度特别有效**。我使用**Webpack**等工具分析依赖树，确保只有必要的模块被包含在生产构建中。此外，我还通过移除冗余函数、简化复杂条件和重组数据处理流程来重构代码，减少不必要的计算。这些优化措施共同将应用性能提升了30%。"

咱们来做一个使用Webpack实现Tree Shaking的简单示例吧。

#### 步骤1：基础项目设置

1. **创建项目文件夹并初始化npm**

首先，咱们创建一个目录，初始化npm，[本地安装webpack](https://webpack.js.org/guides/installation/#local-installation)，并安装[`webpack-cli`](https://github.com/webpack/webpack-cli)（用于在命令行运行webpack的工具）

```bash
mkdir tree-shaking-example && cd tree-shaking-example
npm init -y
```

2. 安装Webpack和Babel

```scss
npm install --save-dev webpack webpack-cli babel-loader @babel/core @babel/preset-env
```

[`import`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import)和[`export`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)语句已经在[ES2015](https://babeljs.io/docs/en/learn/)中标准化了。目前大多数浏览器都支持它们，但仍有一些浏览器不认识这种新语法。不过别担心，webpack本身就支持这些语法哦。

在幕后，webpack实际上会"转译"代码，以便旧版浏览器也能运行它。如果你查看`dist/main.js`，可能会发现webpack是如何做到这一点的，真的很巧妙！除了`import`和`export`，webpack还支持各种其他模块语法，详情请参见[模块API](https://webpack.js.org/api/module-methods)。

需要注意的是，webpack不会改变除`import`和`export`语句之外的任何代码。如果你使用了其他**[ES6特性](http://es6-features.org/)**，请确保通过webpack的[loader系统](https://webpack.js.org/concepts/loaders/)使用像**[Babel](https://babeljs.io/)**这样的转译器。

#### 步骤2：创建示例JavaScript文件

`math.js`（包含未使用代码的工具文件）

```javascript
export function add(a, b) {
  return a + b;
}

export function multiply(a, b) {
  return a * b;
}

// 这个函数在项目中从未被使用
export function subtract(a, b) {
  return a - b;
}
```

`index.js`（只使用'add'函数的主文件）

```csharp
import { add } from "./math.js";

console.log("结果：", add(5, 10));
```

#### 步骤3：配置Webpack以启用Tree Shaking

创建`webpack.config.js`文件

```javascript
const path = require("path");

module.exports = {
  mode: "production", // 启用Tree Shaking
  entry: "./index.js",
  output: {
    filename: "bundle.js",
    path: path.resolve(__dirname, "dist"),
  },
  optimization: {
    usedExports: true, // 启用Tree Shaking
  },
  module: {
    rules: [
      {
        test: /\.js$/,
        exclude: /node_modules/,
        use: {
          loader: "babel-loader",
          options: {
            presets: ["@babel/preset-env"],
          },
        },
      },
    ],
  },
};
```

#### 步骤4：构建并观察Tree Shaking的效果

运行Webpack来打包项目

```undefined
npx webpack
```

> 运行webpack后会发生什么呢？

> 由于`subtract()`**从未被使用**，Webpack会将它从最终的`bundle.js`中**移除**。

> 只有`add()`函数会被包含在内，从而减小包体积并提升性能。

#### Tree Shaking的工作原理

**> ES6模块分析**：Webpack会扫描你的import/export语句。

**> 无用代码消除**：它会移除最终包中未使用的函数。

**> 代码压缩**：在**生产模式**下还会进行额外优化，进一步缩小代码体积。
